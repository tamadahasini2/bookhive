# 📚 BookHive - Online Bookstore

A modern, responsive online bookstore showcasing Indian authors, bestsellers, and popular books.

## 🌟 Features

* 📚 Browse books from multiple categories
* 🔍 Search and filter books
* 📖 Detailed book information
* 🛒 Shopping cart with add, update, and remove functionality
* 💾 Cart persistence using LocalStorage
* 👤 User signup and login pages
* 📝 Contact form with validation
* 📱 Fully responsive design for mobile, tablet, and desktop
* ✨ Loading animation and interactive UI
* 💰 Indian pricing displayed in ₹

## 🛠️ Built With

* **HTML5** - Semantic markup, forms, tables, and page structure
* **CSS3** - Custom styling, Flexbox, Grid, responsive design, and animations
* **JavaScript (ES6+)** - DOM manipulation, event handling, array methods, LocalStorage, and dynamic content
* **Git & GitHub** - Version control
* **GitHub Pages** - Website deployment
